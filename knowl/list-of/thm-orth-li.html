Theorem 6.22 Linear Independence of Orthogonal Sets.

If \(\{\vec u_1,\dots,\vec u_p\}\) is an orthogonal set of vectors, then:
🔗
\begin{equation*} \left\lVert c_1\vec u_1 + \cdots + c_p\vec u_p\right\rVert^2 = c_1^2\lVert\vec u_1\rVert^2 + \cdots + c_p^2\lVert\vec u_p\rVert^2. \end{equation*}
Furthermore, if all the vectors \(\vec u_1\) are nonzero, then the set is linearly independent.
